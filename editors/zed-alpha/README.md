# Расширение Alpha для редактора Zed

Официальное расширение для редактора **Zed**, обеспечивающее полноценную подсветку синтаксиса на основе **Tree-sitter** и интеллектуальные возможности (автодополнение, документация при наведении, диагностика ошибок в реальном времени, строгая типизация `@strict`) через **`alpha-lsp`** для файлов языка **Alpha** (`.alpha`).

---

## 🌟 Возможности расширения

* **Полная подсветка синтаксиса (Syntax Highlighting)**:
  * Директивы: `@strict` — режим профессиональной строгой типизации и безопасности.
  * Ключевые слова: `function`, `var`, `const`, `if`, `else`, `elseif`, `for`, `each`, `in`, `return`, `try`, `catch`, `verify`, `defer`, `check`, `make`, `structure`, `enum`, `module`, `import`, `system`, `public`, `here`.
  * Логические операторы-слова: `and`, `or`, `not`.
  * Типы данных: `int`, `unt` (unsigned 64-bit int), `float`, `string`, `char`, `boolean`, `something`, `nothing`, `vect<T>`, `map<K, V>`, `<int, nothing>`, `Io.File`, `Fs.Dir`.
  * Функции и методы, включая идентификаторы с суффиксом `?` (`is_prime?`, `nothing?`, `empty?`, `something?`).
  * Функции времени и профилирования: `Time.benchmark({ ... })`, `Time.now()`, `Time.now_ms()`, `Time.sleep()`.
  * Литералы: строки с интерполяцией (`{var}`), многострочные строки, hex-цвета (`#FF5733`), символы, числа, булевы значения, `nothing`.
  * Однострочные (`// ...`) и многострочные (`/* ... */`) комментарии.
* **Автозакрытие и подсветка парных скобок**: `{ }`, `[ ]`, `( )`, `" "`, `' '`.
* **Автоматические отступы (Smart Indents)** для блоков и списков параметров.
* **Символьная панель (Outline Panel)**: отображение объявленных функций в панели символов Zed (`Ctrl+Shift+O`).
* **Language Server Protocol (`alpha-lsp`)**:
  * **Диагностика в реальном времени (Real-Time Diagnostics)**: мгновенная подсветка синтаксических ошибок, ошибок компиляции и ошибок типов.
  * **Контроль `@strict`**: мгновенное обнаружение нарушений строгой типизации (нетипизированные переменные, использование `something`/`nothing`, попытки force-unwrap `!?` вместо `check`).
  * **Автодополнение (Completions)**: контекстные подсказки по ключевым словам, типам, функциям стандартной библиотеки (`Io`, `Fs`, `Time`, `Math`, `Env`).
  * **Hover-документация**: подсказки по сигнатурам, типам и директивам при наведении курсора на код.

## 🚀 Как загрузить и установить расширение в Zed

Zed поддерживает прямую установку разрабатываемых расширений (**Dev Extensions**) без необходимости публикации в маркетплейсе.

### Пошаговая инструкция:

1. **Запустите редактор Zed**.
2. Откройте **Командную палитру** (Command Palette):
   * На Windows / Linux: нажмите `Ctrl + Shift + P`
   * На macOS: нажмите `Cmd + Shift + P`
3. Начните вводить и выберите команду:
   ```text
   zed: install dev extension
   ```
4. В появившемся окне выбора папки выберите директорию:
   ```
   D:\RustProjects\alpha-lang\editors\zed-alpha
   ```
   *(папку, в которой находится файл `extension.toml`)*.
5. Нажмите **«Выбрать папку»** (Select Folder).

### ⚙️ Подключение Language Server (`alpha-lsp`)

Соберите бинарник `alpha-lsp` или основной бинарник `alpha`:
```bash
cargo build --release
```
Бинарник `target/release/alpha-lsp.exe` (или `alpha-lsp` на Unix) скопируйте в каталог, находящийся в вашем `PATH`, либо пропишите путь к нему в настройках Zed (`Ctrl+,` -> `settings.json`):

```json
{
  "lsp": {
    "alpha-lsp": {
      "binary": {
        "path": "D:/RustProjects/alpha-lang/target/release/alpha-lsp.exe",
        "arguments": []
      }
    }
  }
}
```

## 🔍 Проверка работы

1. Откройте в Zed любой файл программы Alpha, например `main.alpha`.
2. В правом нижнем углу строки состояния Zed вы увидите язык **Alpha** и статус сервера **alpha-lsp**.
3. При вводе `@strict` или ошибок типизации редактор сразу подсветит проблемные места волнистой линией с объяснением ошибки и подсказкой (`hint`).
4. Нажмите `Ctrl + Shift + O` — откроется список функций в файле (Outline).
5. Нажмите `Ctrl + Space` для вызова автодополнения кода.
